## Running locally

```
SITE_URL=http://127.0.0.1:18924/ CLIENT_DIR=../client npm test
SITE_URL=http://127.0.0.1:18924/ CLIENT_DIR=../client npm run build
python3 -m http.server 18924 --bind 127.0.0.1 --directory dist
```
